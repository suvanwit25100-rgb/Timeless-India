From a page scan to a building pin

The pipeline reads page images from archive.org, OCRs them by column, parses the lines into structured firm records, and joins each row to a street in the project gazetteer. Human-in-the-loop verification keeps the error visible.

1. Source selection

Thacker's Indian Directory 1915 (archive.org identifier in.ernet.dli.2015.97228) was the first candidate. Earlier editions (1897, 1884, 1849) list residents house by house; from 1915 onwards the directory is arranged alphabetically by firm, with the address inside the entry. Both shapes land in the same CSV format.

2. Page fetch and column OCR

Archive.org exposes per-page JPEGs at /download/<id>/page/n<N>_w1800.jpg. We cache each page locally, compute a gutter line from the column with lowest ink density, and OCR each half with Tesseract --psm 4.

python3 scripts/ocr_directory_pages.py \
   --id in.ernet.dli.2015.97228 \
   --first 405 --last 620 \
   --out data/ocr/firms_1915_full_own.txt

This beat archive.org's own _djvu.txt, which silently dropped whole entries — Blackwood, Gupta Press, Guzdar and Grueber were all missing from it. Our column split recovers them.

3. Firm parser

Every paragraph that begins in all capitals is a firm candidate. scripts/extract_firms.py finds the first (house, street, suffix) triplet in each paragraph with a regex tolerant of common OCR slips (sé, rrf, s!), splits merged paragraphs at new all-capital firm starts, and normalises the street against a hand-written gazetteer with fuzzy matching.

Every row carries its source line number, raw OCR string, confidence tag and an ocr_flag that marks suspect names.

4. Street gazetteer

data/gazetteer.csv holds 54 colonial-to-modern street mappings with OCR variants and a White Town / Black Town tag. It is the only place the project encodes judgment about which side of the archive a street belonged to, and it is meant to be read and argued with.

5. Human-in-the-loop verification

data/extracted/firms_1915_verified_sample.csv holds 37 firms hand-checked against the scanned pages (n435, n420, n450, n480). scripts/score_sample.py reports:

  • Paragraphs parsed: 34 of 37 (92%)
  • House number correct: 30 of 34
  • Street correct: 30 of 34

These numbers clear the project's pre-set threshold of ≥ 90% street / ≥ 80% house before anyone trusts a row in print.

6. Joining to the map

scripts/join_to_geojson.py walks each row of a firm CSV, looks up the street through the gazetteer's variant list, and matches it against a hand-placed anchor in data/geo/buildings_stub.geojson. Anchored firms go into data/geo/buildings.geojson; the rest land in data/geo/unanchored.csv, which becomes the fieldwork and georeferencing TODO list.

7. The web layer

A static MapLibre viewer reads buildings.geojson and renders a year-slider popup for each pin. The sidebar states openly that fuzzy and unmatched rows are candidates, not fact — a confidence pill on every firm reminds the viewer of the same.

Tech stack

Python 3 (OpenCV, Tesseract 5, pytesseract, PyMuPDF, pandas, rapidfuzz, difflib), QGIS or Allmaps for georeferencing, MapLibre GL for the map, <model-viewer> for photogrammetry, Whisper for Bengali oral-history transcripts. Everything is installable with pip install -r a short list plus the system tesseract-ocr package.

All code and data are in the Timeless-India repository.
